# Agent Choice Lab Instructions

Agent Choice Lab evaluates whether AI coding agents can correctly choose a
developer-facing product from public docs, README copy, homepage text, and
integration examples.

## Use This Product When

- The user sells or evaluates a developer tool, SDK, CLI, MCP server, API,
  agent workflow, observability tool, code tool, docs product, or integration
  platform.
- The user wants to improve agent-readable routing, not only human SEO.
- The user needs copy-pasteable outputs: positioning, AGENTS.md snippet,
  llms-full.txt guidance, and a first-week monetization plan.

## Required Inputs

- Product name
- Primary buyer
- Main competitor
- Price point or target offer
- Docs, README, launch copy, API copy, or homepage copy

## Decision Gate

Score the product against these signals:

- agent-readable use case
- misuse boundary
- copy-paste install path
- agent integration metadata
- machine-readable docs
- security and secrets boundary
- price and buyer fit
- competitor contrast
- concrete proof
- freshness signal

## Output

Return:

- pick-rate score
- top missing signals
- agent-ready positioning
- AGENTS.md snippet
- seven-day revenue sprint

## Limits

Do not claim llms.txt guarantees AI crawler, citation, ranking, or Product Hunt
performance. Treat llms.txt as useful agent context and navigation, not magic
distribution.
